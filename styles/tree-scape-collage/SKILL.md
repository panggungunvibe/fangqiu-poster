# 树影风景拼贴

把用户的风景原图拼进固定枯树骨架。保留照片真实性，不让生成模型重画景物；树干和枝条始终位于最上层。默认成片为 `1206 × 2310` PNG，不含水印、界面元素或文字。

## 核心造型约束

- 照片不是普通拼图，也不是先切成几何块再叠一棵树。每一处换图边界必须由固定树图的主干、树杈或细枝定义。
- 脚本必须从树的透明蒙版计算连通域，让枝干成为窗格之间的真实隔断；禁止使用矩形、扇形、三角形或任意多边形横穿没有树枝覆盖的开放区域。
- 黑色树枝位于最上层并压住接缝。允许相邻照片在枝条两侧直接换景，但开放区域不能出现直线、折线或锯齿状拼接边。
- 右侧枝梢使用局部闭合形成上、中、下层次，不能让右上单格吞掉画面近三分之一；最大主窗面积应控制在约四分之一以内。
- 若更换固定底图后树枝无法形成 8 个主连通窗格，应停止并重新制作树枝分区，不能退回普通拼接。

## 输入判断

- 固定底图是 [assets/tree-base.jpg](assets/tree-base.jpg)，即白底黑色枯树图。示例成片不是底图。
- 至少需要 6 张不同风景原图。6–7 张时允许对最合适的 1–2 张使用不同裁切重复一次，但不能相邻。
- 建议上传 8–10 张；若希望自动挑片，10–12 张最佳。
- 少于 6 张时停止合成，直接告诉用户还需要几张。不要用纯色块、AI 补景或重复同一裁切凑数。
- 优先使用原始照片。若输入是带状态栏、评论区、页码、平台水印的截图，先寻找同组原图；找不到时仅在能完整裁掉界面元素的情况下使用。

## 选片与排布

先查看全部图片，再选 8 个窗格所需的素材。选择与排序遵守这些视觉规则：

1. 选 1 个主色家族覆盖约一半画面，例如秋日金橙、湖水蓝青或森林绿；再选 2–3 张邻近色和 1–2 张对比色。避免 8 张各自抢色。
2. 高饱和橙红、霓虹色或大面积纯亮色只能放在“正中点景”或“左上角”等小窗；不能放入左右主窗，否则视觉面积会被进一步放大。
3. 顶部放较暗、较冷或留白较多的远景，压住画面；中部放信息最清楚、层次最丰富的主景；底部用较深色水面、草地、树林或岩石收住重心。
4. 相邻窗格不要同时高饱和、同时高亮或拥有相似地平线。让冷暖、明暗或远近至少有一项变化。
5. 同类景物不要连续出现三格。若有水面、山林、树叶、天空，交错分布。
6. 拒绝明显糊片、重度过曝、低分辨率截图、带大字或大水印的素材。

固定窗格顺序按树枝自然连通域面积排序为：右上主窗、左上主窗、底部、左下、右下、左中、正中点景、左上角。排列后把路径按此顺序传给脚本，并使用 `--keep-order`。

## 裁切规则

- 每张照片用“覆盖式裁切”，不能拉伸。默认由脚本寻找高信息区域。
- 若主体很明确，使用 `--focus` 为每格提供归一化焦点 `x,y`；例如主体位于画面右上是 `0.75,0.25`。
- 山峰、建筑、动物等主体不能被树干截成两半；把主体移到窗格较开阔的一侧。
- 地平线优先放在窗格上三分之一或下三分之一，避免八格都在同一高度。
- 大面积天空、水面可承担顶部或较宽窗格；细密树林、花叶适合窄窗格；最清晰的层次景放中部主窗。
- 不要为了保留全部内容而缩小留黑边。

## 合成

运行：

```bash
python3 scripts/compose_tree_collage.py \
  --inputs <右上主窗> <左上主窗> <底部> <左下> <右下> <左中> <正中点景> <左上角> \
  --keep-order \
  --output <输出路径>.png
```

有明确主体时可增加：

```bash
--focus "0.50,0.40;0.65,0.35;0.40,0.55;0.50,0.50;0.35,0.50;0.60,0.45;0.45,0.55;0.55,0.50"
```

如果用户给了 9–12 张但不要求人工编排，可以省略 `--keep-order`，让脚本按清晰度、色彩差异与相邻对比自动选 8 张。`--grade cohesive` 用于同季节、同地点组图；`--grade vivid` 用于蓝绿湖水或秋色；默认 `auto`。

脚本依赖 Pillow 与 NumPy。缺少依赖时，只提示安装缺少项，不要改用会重绘风景的图像生成。

## 验收

查看输出并确认：

- 枯树轮廓完整且固定，位于所有照片上方；右下角原水印已被排除。
- 画布无白缝、黑边、拉伸、界面元素和新增文字。
- 所有照片交界都沿主干、树杈或细枝变化；开放区域没有任何独立的直线、斜线或多边形切边。
- 脚本输出的 `Branch-aligned seam coverage` 应不低于 `95%`；低于该值时不得交付，需检查树蒙版或分区参数。
- 右上主窗不应形成贯穿大半画面的单一色块；橙红等强暖色必须位于小窗。
- 8 个窗格可辨但不杂乱；主景突出；上下有重量平衡；相邻窗格有适度色彩或明暗差。
- 重复照片不相邻且裁切明显不同。
- 若只有局部不理想，优先调整该格的顺序或 `--focus`，不要整体重做。

完成后把最终 PNG 以内嵌预览形式展示给用户，并说明使用了几张照片、是否有重复裁切以及保存路径。
